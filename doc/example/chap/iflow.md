## 论文主题

### 研究领域
- **多模态大语言模型（VLM/LLM）安全**
- **人工智能安全与伦理**

### 核心研究内容

#### 1. 安全风险分类
正常场景下面临的多模态安全风险主要分为：
- 文本风险
- 图片风险
- 图文联合风险

#### 2. 安全挑战

**核心难点：**
1. **目标冲突**：安全目标（不输出风险内容）与模型指令遵循能力相互矛盾，强化安全能力会削弱通用能力
2. **边界不确定性**：不同主体对安全边界的认知存在差异

**具体挑战：**
- **过度拒绝与拒绝不足**：模型在安全性和有用性之间的博弈，导致要么输出有害内容，要么过度保守
- **越狱攻击**：恶意用户通过对抗性提示词诱导模型绕过安全准则
- **幻觉问题**：模型生成事实性错误或逻辑不连贯内容，在视觉语言模型中尤为严重
- **种族歧视与偏见**：模型在预训练过程中吸收社会偏见，在文本和图像识别中被放大

#### 3. 研究聚焦
- 提高输出安全
- 应对拒绝不足和越狱攻击
- 通过合理利用外挂知识库解决幻觉问题

#### 4. 安全增强方法
- **输入输出安全审核与后处理**
  - 使用轻量模型进行前置筛查和后置校验
  - 代表性模型：Llama-Guard、Llava-Guard、Shield-Gemma、Qwen3-Guard、WildGuard
  - 优点：实现简洁、与主模型解耦、工程实用性强
  - 局限性：依赖完整审查链路、泛化能力瓶颈、维护成本高

## 编译说明

使用 LaTeX 编译器（如 XeLaTeX）编译主文件即可生成完整的 PDF 论文。

```bash
xelatex main.tex
```

## 注意事项

1. 所有 `.tex` 文件使用 UTF-8 编码
2. 建议使用 XeLaTeX 编译以获得最佳中文支持
3. 编译过程中会生成 `.aux` 等辅助文件
4. 引用的图片文件需要放在对应目录下（如二维码图片需命名为 `barcode`）
