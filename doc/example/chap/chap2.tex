\chapter{相关工作}
本章围绕本文研究所涉及的关键技术基础与代表性研究进展展开综述。首先介绍大模型微调与安全对齐的主要技术路线，其次梳理思维链推理及其在安全场景中的演进，随后总结通用大模型在实际应用中面临的核心风险与现有防御方法，为后续提出多模态安全对齐方法提供理论依据与研究参照。

\section{大语言模型训练范式}
\subsection{预训练范式与缩放定律}

大语言模型的成功建立在大规模预训练范式基础之上。通过在海量文本语料上进行自监督学习，模型能够习得语言的结构、语义和世界知识。
缩放定律揭示了模型性能与计算量、参数规模和数据量之间的幂律关系，为模型设计提供了理论指导\supercite{DBLP:journals/corr/abs-2001-08361}。缩放定律可以表示为：
\begin{equation}
L(C, D, N) = \left(\frac{N_c}{N}\right)^\alpha + \left(\frac{D_c}{D}\right)^\beta
\end{equation}
其中$L$表示损失函数，$C$表示计算量，$D$表示数据量，$N$表示模型参数量，$N_c$和$D_c$是临界值，$\alpha$和$\beta$是幂律指数。

在预训练阶段，模型主要采用自监督学习目标，如掩码语言建模（Masked Language Modeling，MLM）和因果语言建模（Causal Language Modeling，CLM）。

掩码语言建模（Masked Language Modeling，MLM）的目标函数为：
\begin{equation}
% \mathcal{L}_{\text{MLM}} = -\sum_{i \in \mathcal{M}} \log P(x_i \mid \mathbf{x}_{\setminus \mathcal{M}})
L_{\mathrm{MLM}} = -\sum_{i \in M} \log P(x_i \mid x_{-M})
\end{equation}
其中$M$表示被掩码的位置集合，$x_{-M}$表示去除掩码位置后的上下文。

因果语言建模的目标函数为：
\begin{equation}
L_{\mathrm{CLM}} = -\sum_{t=1}^{T} \log P(x_t \mid x_{<t})
\end{equation}
其中$x_{<t}$表示时刻$t$之前的所有 token。
随着模型规模扩大，模型会展现出涌现能力，即在小规模模型中不存在的能力在大规模模型中突然出现\supercite{wei2022emergentabilitieslargelanguage}。
这些能力包括上下文学习、指令遵循和复杂推理等。
相关研究工作证明了预训练语言模型作为少样本学习器的强大能力，即无需显式训练即可通过提供示例来完成新任务\supercite{DBLP:conf/nips/BrownMRSKDNSSAA20}。这种能力使得大模型具备广泛的适用性，
但也暴露了其在指令遵循方面的不足，为指令微调的发展提供了动机。

\subsection{指令微调技术}
指令微调是指在预训练基础上，通过监督学习训练模型遵循自然语言指令完成特定任务的方法\supercite{DBLP:conf/iclr/WeiBZGYLDDL22}。相关研究首次系统性地研究了指令微调的效果，证明了通过多任务指令微调可以显著提升模型的零样本和少样本性能。
指令微调的核心思想是将各种NLP任务统一为指令-响应格式，使模型学习到通用的指令遵循能力。相关研究发现随着模型规模和指令数据量的增加，模型的指令遵循能力持续提升\supercite{DBLP:journals/corr/abs-2210-11416}。
在实践层面，相关研究证明了即使使用相对较小的指令数据集，也能在预训练模型基础上获得良好的指令遵循能力\supercite{DBLP:journals/corr/abs-2305-15011}。这激发了开源社区对指令微调模型的广泛研究和应用。
现如今指令微调已经成为面对不同领域下游任务的首选，并在工业界得到了广泛应用。

然而，指令微调仍面临挑战，指令微调的数据质量高低直接影响模型的性能，大规模进行指令微调会导致灾难性遗忘，训练本身也极其容易出现过拟合，欠拟合等现象，严重影响最终模型表现。

\subsection{基于人类反馈的强化学习技术}
尽管指令微调提升了模型遵循指令的能力，但模型的输出仍可能与人类价值观和期望存在偏差。人类反馈强化学习（Reinforcement Learning from Human Feedback，RLHF）则通过引入人类偏好信号，使模型输出与人类价值观对齐。
人类反馈强化学习（RLHF）通常包含三个阶段：首先使用人类标注的偏好数据训练奖励模型（Reward Model，RM），然后使用强化学习算法（如PPO（Proximal Policy Optimization））优化策略模型，使生成的输出获得更高的奖励\supercite{DBLP:conf/nips/Ouyang0JAWMZASR22}。相关研究进一步将RLHF扩展到有害性（Harmlessness）对齐，训练出既有帮助性又无害的助手\supercite{DBLP:journals/corr/abs-2204-05862}。
Anthropic团队提出的宪法人工智能（Constitutional AI，CAI）方法探索了利用AI反馈替代部分人类反馈的可能性，通过预定义的宪法原则指导模型自我批评和修正，降低了人类反馈强化学习（RLHF）对大规模人类标注的依赖\supercite{DBLP:journals/corr/abs-2212-08073}。
同样，相关研究也指出RLHF面临多重挑战。一方面，训练过程复杂且不稳定，需要大量高质量的偏好数据；另一方面，强化学习优化可能导致训练不稳定和灾难性遗忘。此外，RLHF会引入“对齐税”（Alignment Tax），即对齐偏好的过程可能降低模型在通用任务上的性能。

\subsection{偏好优化与对齐方法}
为克服RLHF的局限性，研究者提出了多种替代方案。直接偏好优化（Direct Preference Optimization，DPO）通过将奖励模型隐式地表示为策略函数的函数，避免了显式训练奖励模型和强化学习过程，显著简化了训练流程\supercite{DBLP:conf/nips/RafailovSMMEF23}。
DPO的核心思想是直接在策略空间优化偏好数据，通过分析偏好对中的正负样本，推导出策略优化的目标函数。DPO的目标函数可以表示为：
\begin{equation}
L_{\mathrm{DPO}}(\pi_\theta; x, y_w, y_l) = -E_{(x, y_w, y_l) \sim D} \left[ \log \sigma \left( \beta \log \frac{\pi_\theta(y_w \mid x)}{\pi_\theta(y_l \mid x)} \right) \right]
\end{equation}
其中$\pi_\theta$表示参数为$\theta$的策略模型，$x$表示输入，$y_w$和$y_l$分别表示偏好对中的正样本和负样本，$\beta$是温度参数，$\sigma$表示sigmoid函数。这种方法在保持与人类反馈强化学习(Reinforcement Learning from Human Feedback，RLHF)相当性能的同时，具有更好的稳定性和计算效率。Kahneman-Tversky优化（Kahneman-Tversky Optimization，KTO）进一步简化了偏好数据的需求，仅需单个样本的二元反馈即可进行有效优化\supercite{DBLP:journals/corr/abs-2402-01306}。
除了DPO和KTO，还有其他偏好优化方法，如身份偏好优化（Identity Preference Optimization，IPO）和相对优势优化（Relative Advantage Optimization，RAO）等。这些方法各有优劣，在不同场景下表现出不同的特性。

\section{大模型思维链发展}
\subsection{思维链的提出}
思维链（Chain-of-Thought，CoT）推理是一种提升大模型推理能力的技术。其核心思想是通过在最终答案之前生成中间推理步骤，引导模型进行逐步推理而非直接跳跃到答案。研究发现，通过在少样本提示中包含推理过程示例，能够显著提升模型在算术推理、常识推理等复杂任务上的性能\supercite{DBLP:conf/nips/Wei0SBIXCLZ22}。
思维链（CoT）推理的优势在于多个方面。首先，它利用了模型在预训练过程中学到的逻辑推理能力，将复杂问题分解为更易处理的子问题。其次，中间推理步骤提供了可解释性，使模型的决策过程更加透明。然而，思维链（CoT）推理也存在局限性，当推理路径过长或推理步骤出现错误时，最终答案的正确性会受到影响。
\subsection{ReAct框架}
ReAct（Reasoning and Acting）框架将推理与行动相结合，使大模型能够通过调用外部工具和API来解决复杂问题。ReAct框架的核心思想是在推理过程中交替进行思考和行动，使模型能够根据当前推理状态决定下一步的行动，并根据行动结果调整推理策略\supercite{DBLP:conf/iclr/YaoZYDSN023}。
ReAct框架通常包含两种操作类型：思考（Thought）和行动（Action）。思考操作生成关于问题状态的推理或观察，行动操作执行具体的工具调用或API请求。通过这种交替模式，模型能够在推理过程中动态获取外部信息，从而解决需要实时数据或专业知识的问题。
ReAct框架在问答、知识检索、多步骤推理等任务上表现出色，显著提升了模型的实用性和可靠性。然而，其成功依赖于可用工具的质量和数量，以及模型对工具使用的理解能力。
\subsection{多模态思维链}
随着多模态大模型的发展，思维链（CoT）推理被扩展到视觉-语言场景。多模态思维链（Visual Chain-of-Thought，VCoT）方法旨在通过在视觉理解和文本生成之间建立推理链，提升模型在多模态推理任务上的性能。
多模态思维链（VCoT）方法的核心思想是在回答视觉问题时，先生成对图像内容的逐步分析和推理，然后基于这些中间步骤生成最终答案。这种分层推理方式使模型能够更好地理解复杂的视觉场景，处理需要多步推理的视觉问答任务。
多模态CoT面临的独特挑战包括：如何设计有效的视觉推理步骤、如何在视觉特征和文本推理之间建立关联、如何处理图像中的模糊性和歧义等。研究表明，精心设计的多模态CoT方法能够显著提升模型在视觉推理、图像描述、场景理解等任务上的性能\supercite{DBLP:conf/aaai/ChenZSHSGG24}。

\subsection{思维链在大模型安全领域的应用}
安全思维链（Safety Chain-of-Thought，Safety CoT）是思维链（CoT）推理在安全领域的应用，旨在通过显式的安全推理过程提升模型的安全识别和防御能力。早期的安全方法主要依赖于简单的分类模型，而安全思维链（Safety CoT）引入了推理层，使模型能够分析问题的安全性质和潜在风险。
GuardReasoner-VL等人提出的安全推理机制训练模型在输出安全判断前先生成详细的安全推理过程，包括识别潜在风险、分析攻击意图、评估危害程度等。这种推理增强的方法显著提升了模型对复杂攻击的识别能力\supercite{DBLP:journals/corr/abs-2505-18531}。
Safety CoT的演进经历了从简单拒答到推理增强的发展过程。早期方法主要基于“问题-拒答”对进行训练，导致模型缺乏对安全本质的理解。现代Safety CoT方法通过引入安全推理链，使模型能够解释为何某个请求是不安全的，从而提升安全判断的准确性和可解释性。
安全思维链的应用不仅限于攻击识别，还包括安全策略的动态调整、多模态安全推理、对抗性攻击的防御等。随着安全威胁的不断演化，Safety CoT方法将继续在模型安全领域发挥重要作用。

\section{通用大模型面临的安全风险}
近年来，大语言模型（Large Language Model，LLM）的飞速发展显著提升了自然语言处理的基准，并进一步催生了视觉语言模型（Vision-Language Model，VLM）的多模态理解能力\supercite{wang-adashield-eccv-2024, DBLP:journals/corr/abs-2505-24208}。然而，随着模型参数量和应用场景的扩张，其潜藏的安全风险也愈发凸显\supercite{DBLP:conf/cvpr/WangGL025}。

正常场景中，面临的多模态安全风险主要可以分为以下几类：文本风险、图片风险、图文联合风险。

安全的难点在于：安全任务和其他任务是背道而驰的。安全的目标是不输出风险内容，而模型内生的指令遵循能力又要求模型尽可能按照指令进行输出，因此强化安全能力势必削弱通用能力。
以及边界的不确定性。各类主体针对安全边界的认知存在明显差异，因此很多第三方的安全边界相对缺乏参考价值。

现有的安全性研究主要集中在以下几个核心挑战：

\begin{itemize}
    \item \textbf{过度拒绝与拒绝不足：} 模型在安全性和有用性之间存在帕累托前沿（Pareto Frontier）的博弈。这导致模型要么容易被欺骗输出有害内容，要么过度保守，拒绝回答合法的良性请求（Overrefusal）。
    
    \item \textbf{越狱攻击：} 恶意用户可以通过精心设计的提示词（Adversarial Prompts）诱导模型绕过内部安全准则，生成不当或有害内容，如非法行为指令、自残建议等\supercite{DBLP:conf/iclr/AndriushchenkoC25, Robey2023SmoothLLMDL}。
    
    \item \textbf{幻觉问题：} 模型生成事实性错误或逻辑不连贯内容的现象\supercite{DBLP:journals/csur/JiLFYSXIBMF23,DBLP:conf/emnlp/LiCZNW23}，在视觉语言模型中尤为严重。
    
    \item \textbf{种族歧视与偏见：} 模型在海量互联网数据预训练过程中，不可避免地吸收了人类社会存在的社会偏见\supercite{DBLP:conf/acl/ParrishCNPPTHB22,DBLP:conf/acl/BlodgettBDW20}。这种偏见不仅体现在文本回复中，更在图像识别与关联中被放大。例如，模型可能在视觉识别中对特定族裔产生刻板印象\supercite{DBLP:conf/fat/BenderGMS21}，或在招聘、风险评估等下游任务中表现出系统性的种族或性别歧视。这不仅是技术挑战，更是违反 AI 伦理准则的核心问题，直接影响了模型的大规模部署与社会合规性。
\end{itemize}

我们的研究主要聚焦于提高输出安全，应对拒绝不足和越狱攻击，以及通过更合理地利用外挂知识库，解决可能出现的安全问题。

\section{推理与部署阶段的安全增强方法}
推理与部署阶段的增强主要聚焦于在不修改模型参数的前提下，如何提升模型的输出安全能力。
\subsection{输入输出安全审核与后处理}
通过构建完整的安全审查链路以阻断不良信息的正常流转，是当前输入输出安全防护领域的主流思路，也是工业界应用最为广泛的技术方案之一。其核心设计理念在于引入一个参数量更小的轻量模型，专门负责对输入内容与输出结果进行安全校验。
该校验过程可灵活作用于两个环节：既可以对用户发起的查询请求进行前置筛查，也可在主模型完成推理生成后，对输出内容进行后置校验。典型代表模型包括 Llama-Guard\supercite{Inan2023LlamaGL,Helff2024LLavaGuardVS,DBLP:journals/corr/abs-2407-21772,DBLP:journals/corr/abs-2510-14276,DBLP:conf/nips/HanREJL00D24}等。
具体而言，在主模型完成推理任务后，由该轻量化校验模型评判输出结果是否违反预设安全准则，若检测到违规内容，则触发对应的后处理流程。
后处理相关的工作有VLMGuard-R1、MLLM-Protector等\supercite{Wang2024MLLMasaJudgeFI, DBLP:journals/corr/abs-2504-10081}。
其主要思路是\supercite{Wang2024MLLMasaJudgeFI}是模块化组件在检测到有害输出已经产生的情况下，单独对有害输出做无害化改写，以达到保障输出安全的能力。
此类方法实现逻辑简洁，与主模型训练及推理流程完全解耦，具备较强工程实用性。但其局限性在于：安全能力依赖完整审查链路部署，若直接调用开源模型，仍可能生成违规内容。此外，前置分类模型泛化能力有限，当安全规则频繁调整时，需反复训练，维护成本较高。

\subsection{推理时控制与自反思机制}

推理时控制与自反思聚焦于推理过程中的实时安全管控。核心思路是在模型预测下一词元时嵌入特定采样策略，引导模型生成安全合规内容。
该类方法无需对主模型进行微调，仅在词元输出阶段介入调控，适配实时场景需求，并可动态识别和修正潜在风险。例如，Qwen3-Guard \supercite{DBLP:journals/corr/abs-2510-14276}的工作提出流式版本以适配实时场景；ETA 通过对句子的 Best-of-N 前缀进行推理，实现过程级安全控制\supercite{DBLP:conf/iclr/DingLZ25}。
和上面提到的后处理方法相比，他是在输出且尚未结束的过程中介入管控，避免了完整输出的生成成本，相对更早地发现潜在风险并进行修正。

\subsection{检索增强与部署级安全}

大语言模型作为概率模型，其世界知识主要来源于预训练和中期训练阶段。由于训练成本高且周期长，当知识因时效性过时，可能引发安全风险。
为此，引入检索增强生成（RAG）机制，以解决时效性问题导致的模型幻觉。传统方法是引入外挂知识库，在回答前检索相关文档以辅助生成，减少幻觉。
伴随智能体能力发展，工业界将知识检索作为工具调用方式，由模型自主选择是否调用。例如 Search-R1 通过在思考过程中调用检索能力并进行多轮检索，解决多跳复杂推理问题，同时隐含具备处理知识密集型安全问题的潜力。
我们希望通过引入该机制强化模型的安全反思能力。

\section{基于模型训练的安全增强方法}
相较于推理阶段的介入，基于模型训练的方法旨在从根本上重塑模型参数分布与潜在表征，使其内化安全规范。训练范式已从单纯记忆不安全样本，演进为培养模型的安全推理能力（Safety Reasoning）与价值观对齐（Value Alignment）。
\subsection{构建适配器与轻量化安全模块}

该类方法在冻结主干参数的前提下，通过参数高效微调（Parameter-Efficient Fine-Tuning，PEFT）注入安全知识，降低训练成本并减少灾难性遗忘。
例如Zong等人的工作\supercite{DBLP:conf/icml/ZongBYYH24}使用 LoRA(Low-Rank Adaptation)技术进行安全微调。但后续研究\supercite{DBLP:journals/corr/abs-2505-24208}指出，仅文本层面微调难以抵御视觉越狱攻击。
因此，研究开始聚焦视觉-语言对齐层。例如 SafeVLM 在视觉编码器后引入“安全投影仪（Safety Projector）”和安全 Token，用于拦截视觉风险特征。VLMGuard-R1 \supercite{Chen2025VLMGuardR1}提出多模态提示重写器，通过后视分析与多模态因果分析将潜在风险查询转化为安全指令\supercite{DBLP:conf/cvpr/ZhangCZGZFYJQ0Z25, DBLP:journals/corr/abs-2508-18649}。
此类方法具备模块化灵活性，但在极隐晦跨模态攻击下仍受限于轻量模块表征能力。

\subsection{融入推理过程的安全有监督微调}

传统 SFT 依赖“问题-拒答”对进行训练，导致模型缺乏对“不安全原因”的深层理解，即“安全推理鸿沟（Safety Reasoning Gap）”。
为此，引入安全思维链（Safety CoT）。例如 GuardReasoner-VL 训练模型在输出最终标签前先生成安全推理过程，从而提升复杂攻击识别率。MIRage 数据集通过多图输入与安全 CoT 标签训练模型进行风险推理\supercite{DBLP:journals/corr/abs-2505-18531}。 deliberative alignment 方法进一步证明了推理能力在安全对齐中的重要作用\supercite{guan-deliberative-alignment-2024}。
实验表明，该方法不仅降低攻击成功率，在部分通用任务上还提升性能。
此外，仅利用包含拒绝回复的良性指令数据进行微调，也可有效纠正模型的过度顺从偏差（Compliance Bias）。

\subsection{基于反馈的偏好对齐优化}

在 SFT 之后，偏好对齐阶段旨在实现模型输出与人类价值观的精细对齐，通常采用 RLHF 或 DPO。

传统 RLHF 面临“对齐税（Alignment Tax）”问题。Safe RLHF-V 提出多模态反馈强化学习框架，通过构建包含有用性与安全性双重偏好的数据集（BeaverTails-V），并建模为受约束优化问题，在最大化有用性的同时确保安全性阈值\supercite{DBLP:journals/corr/abs-2505-18531}。

此外，PRISM 方法捕捉视觉与文本模态间细粒度交互进行偏好建模\supercite{DBLP:journals/corr/abs-2508-18649}。GuardReasoner-VL 在 RL 阶段引入针对推理过程的奖励信号，确保安全判断基于逻辑推导\supercite{DBLP:conf/nips/ZouPWDLAKFH24}。

未来安全训练将不再局限于简单拒答，而是向更具解释性、兼顾通用能力的精细化方向发展。

\section{检索增强生成发展}
\subsection{检索增强生成基本原理}

检索增强生成（Retrieval-Augmented Generation，RAG）是一种结合信息检索和生成式模型的技术，旨在解决大语言模型的知识时效性限制和幻觉问题\supercite{DBLP:conf/nips/LewisPPPKGKLYR020}。检索增强生成(Retrieval-Augmented Generation，RAG)的基本思想是在生成回答之前，先从外部知识库中检索相关文档，然后将检索到的文档作为上下文提供给生成模型，从而提升回答的准确性和可靠性。

形式化地，给定查询$q$和外部知识库$D=\{d_1, d_2, \ldots, d_N\}$，RAG过程可以表示为：
\begin{equation}
D_k = \mathrm{Retrieve}(q, D, k)
\end{equation}
其中$\mathrm{Retrieve}(q, D, k)$表示从知识库中检索出与查询$q$最相关的前$k$个文档$D_k=\{d_{i_1}, d_{i_2}, \ldots, d_{i_k}\}$。

基于检索到的文档，生成器产生最终回答$a$：
\begin{equation}
a = \mathrm{Generate}(q, D_k) = \arg\max_a P(a \mid q, D_k)
\end{equation}
其中$P(a \mid q, D_k)$表示在给定查询和检索文档的条件下生成回答$a$的概率。

RAG方法通常包含三个主要组件：检索器（Retriever）、生成器（Generator）和重排序器（Reranker）。检索器负责从海量文档中找到与查询相关的候选文档，生成器基于检索到的文档生成回答，重排序器对检索结果进行精细化排序以提升相关性。

与传统预训练模型相比，RAG具有显著优势：首先，它能够访问最新的信息，不受训练数据时间范围的限制；其次，通过引用外部文档，RAG提供了答案的可追溯性；最后，RAG可以有效减少模型幻觉，提升事实准确性。

\subsection{检索方法与技术发展}

检索方法的发展经历了从基于关键词到基于语义理解的演进。早期方法主要采用TF-IDF、BM25等传统信息检索技术，通过精确匹配关键词来查找相关文档。然而，这些方法在处理语义相似但词汇不匹配的查询时效果有限。

BM25是一种经典的信息检索算法，其相关性评分函数定义为：
\begin{equation}
\mathrm{BM25}(q, d) = \sum_{i=1}^{|q|} \mathrm{IDF}(q_i) \cdot \frac{f(q_i, d) \cdot (k_1 + 1)}{f(q_i, d) + k_1 \cdot (1 - b + b \cdot \frac{|d|}{\mathrm{avgdl}})}
\end{equation}
其中$q_i$表示查询$q$中的第$i$个词，$f(q_i, d)$表示词$q_i$在文档$d$中的频率，$|d|$表示文档$d$的长度，$\mathrm{avgdl}$表示文档库中文档的平均长度，$k_1$和$b$是可调参数。

逆文档频率（IDF）的计算公式为：
\begin{equation}
\mathrm{IDF}(q_i) = \log\frac{N - n(q_i) + 0.5}{n(q_i) + 0.5}
\end{equation}
其中$N$是文档总数，$n(q_i)$是包含词$q_i$的文档数量。

随着深度学习的发展，基于稠密向量的检索方法成为主流。Dense Passage Retrieval（DPR）使用双编码器架构，将查询和文档映射到同一向量空间，通过计算向量相似度进行检索\supercite{DBLP:conf/emnlp/KarpukhinOMLWEC20}。

在稠密检索中，查询$q$和文档$d$的相似度通过它们的向量表示计算：
\begin{equation}
\mathrm{sim}(q, d) = \frac{v_q \cdot v_d}{\|v_q\| \cdot \|v_d\|}
\end{equation}
其中$v_q = E_q(q)$和$v_d = E_d(d)$分别是查询编码器$E_q$和文档编码器$E_d$的输出向量。

检索过程可以表示为：
\begin{equation}
D_k = \mathrm{topk}_{d' \in D} \, \mathrm{sim}(q, d')
\end{equation}

这种方法能够更好地捕捉语义相似性，显著提升检索质量。

进一步的改进包括：
\begin{itemize}
    \item \textbf{混合检索} —— 结合稀疏检索（如BM25）和稠密检索的优势，提升检索的精确性和召回率
    \item \textbf{多向量检索} —— 使用多个向量表示文档的不同部分，支持更细粒度的检索
    \item \textbf{学习型检索} —— 通过端到端训练优化检索器，使其更好地适应下游任务
\end{itemize}

\subsection{多模态检索增强生成}

随着多模态大模型的发展，检索增强生成也被扩展到多模态领域。多模态RAG（Multimodal RAG）能够处理文本、图像、音频等多种模态的查询和文档。

多模态RAG面临的独特挑战包括\supercite{DBLP:journals/corr/abs-2504-08748}：
\begin{enumerate}
    \item \textbf{跨模态检索} —— 需要建立不同模态之间的语义关联，支持跨模态的相似性计算
    \item \textbf{多模态表示学习} —— 需要学习统一的向量空间，使不同模态的表示能够相互比较
    \item \textbf{多模态融合} —— 在生成阶段需要有效融合来自不同模态的检索结果
\end{enumerate}

代表性工作包括：
\begin{itemize}
    \item \textbf{视觉RAG} —— 支持图像查询或图像-文本混合查询的检索系统
    \item \textbf{多模态知识库} —— 包含图像、文本、表格等多种形式的知识库
    \item \textbf{多模态检索增强生成} —— 结合多模态检索和生成的端到端系统
\end{itemize}

\subsection{智能体中的检索应用}

随着大模型智能体能力的发展\supercite{DBLP:conf/nips/SchickDDRLHZCS23}，
检索被作为重要的工具集成到智能体系统中\supercite{Wang_2024}。
智能体可以根据任务需求自主决定何时调用检索能力，以及如何使用检索结果。

检索在智能体中的应用模式包括\supercite{Wang_2024}：
\begin{enumerate}
    \item \textbf{知识查询} —— 智能体通过检索获取实时或专业知识
    \item \textbf{多跳推理} —— 通过多次检索和推理解决复杂问题
    \item \textbf{工具调用} —— 智能体将检索作为工具调用的一部分，与其他工具协同工作
\end{enumerate}

代表性系统如Search-R1\supercite{DBLP:journals/corr/abs-2503-09516}展示了智能体在思考过程中调用检索工具进行多跳推理的能力。
这种自主检索能力显著提升了智能体在知识密集型任务中的表现。而这种能力同样可以迁移到安全生成任务中

\subsection{检索增强生成的安全性考虑}

虽然RAG通过引入外部知识能够减少幻觉，但也引入了新的安全挑战。
多项研究指出\supercite{Liang2025SafeRAG, Tan2024GluePizza}, 检索增强生成会导致原生模型安全能力发生严重退化\supercite{An2025RAGSafety}, 
并且往往会输出不安全内容, 如Bang An\supercite{An2025RAGSafety}的工作, 给出了一个核心结论:
RAG 不会提升安全性，反而可能降低, 即使模型是安全的, 检索文档也是安全的, 仍有可能产生有害输出, 根本原因是现有文档会RAG会改变模型的安全分布（safety profile）,
这不仅仅出现在普通LLM, RAG智能体\supercite{Yu2025SafetyDevolution}甚至会比“未对齐模型”还更不安全。

\section{本章小结}

本章系统梳理了与本文研究相关的技术基础与代表性工作，为后续方法设计提供了理论依据与研究参照。

在大模型训练范式方面，本章介绍了预训练阶段的缩放定律、掩码语言建模与因果语言建模目标，以及指令微调技术如何通过统一任务格式提升模型的零样本和少样本性能。同时，阐述了人类反馈强化学习（RLHF）及其替代方案（如DPO、KTO）在价值观对齐中的应用，分析了各方法的优势与局限。

在思维链发展方面，本章回顾了思维链（CoT）推理的提出背景与核心思想，介绍了ReAct框架如何将推理与工具调用相结合，以及多模态思维链在视觉-语言任务中的扩展。特别地，重点分析了安全思维链（Safety CoT）在安全领域的应用演进，从简单拒答到推理增强的发展过程。

在安全风险与防御方法方面，本章归纳了通用大模型面临的四类核心风险：过度拒绝与拒绝不足、越狱攻击、幻觉问题以及种族歧视与偏见。进而从推理部署阶段和模型训练阶段两个维度，系统总结了现有的安全增强方法，包括输入输出审核、推理时控制、适配器微调、融入推理过程的安全有监督微调以及基于反馈的偏好对齐优化。

在检索增强生成方面，本章阐述了RAG的基本原理、检索方法的技术演进（从BM25到稠密向量检索）、多模态RAG的挑战以及智能体中的检索应用模式，并讨论了检索增强生成面临的安全性考虑。

综上所述，现有方法在提升模型安全性方面取得了显著进展，但仍存在安全边界模糊、数据分布不均衡、复杂攻击防御能力不足等问题，这为本文提出融合规则约束与安全思维链的训练范式提供了研究动机与改进空间。
