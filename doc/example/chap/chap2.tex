\section{大模型微调}
\subsection{预训练范式与能力形成}

大语言模型的成功建立在大规模预训练范式基础之上。通过在海量文本语料上进行自监督学习，模型能够习得语言的结构、语义和世界知识。Kaplan等人\cite{kaplan2020scaling}提出的缩放定律揭示了模型性能与计算量、参数规模和数据量之间的幂律关系，为模型设计提供了理论指导。

在预训练阶段，模型主要采用自监督学习目标，如掩码语言建模（Masked Language Modeling）和因果语言建模（Causal Language Modeling）。随着模型规模扩大，模型展现出涌现能力，即在小规模模型中不存在的能力在大规模模型中突然出现\cite{wei2022emergence}。这些能力包括上下文学习、指令遵循和复杂推理等，为后续微调奠定了基础。

Brown等人\cite{brown2020language}的工作证明了预训练语言模型作为少样本学习器的强大能力，即无需显式训练即可通过提供示例来完成新任务。这种能力使得大模型具备广泛的适用性，但也暴露了其在指令遵循方面的不足，为指令微调的发展提供了动机。

\subsection{指令微调}

指令微调是指在预训练基础上，通过监督学习训练模型遵循自然语言指令完成特定任务的方法。Wei等人\cite{wei2022finetuned}首次系统性地研究了指令微调的效果，证明了通过多任务指令微调可以显著提升模型的零样本和少样本性能。

指令微调的核心思想是将各种NLP任务统一为指令-响应格式，使模型学习到通用的指令遵循能力。Chung等人\cite{chung2022scaling}进一步研究了指令微调的缩放行为，发现随着模型规模和指令数据量的增加，模型的指令遵循能力持续提升。

在实践层面，Taori等人\cite{taori2023alpaca}证明了即使使用相对较小的指令数据集，也能在预训练模型基础上获得良好的指令遵循能力。这激发了开源社区对指令微调模型的广泛研究和应用。然而，指令微调仍面临挑战，包括数据质量对性能的敏感性、任务多样性不足导致的泛化能力有限等问题。

\subsection{人类反馈强化学习}

尽管指令微调提升了模型遵循指令的能力，但模型的输出仍可能与人类价值观和期望存在偏差。人类反馈强化学习（Reinforcement Learning from Human Feedback, RLHF）通过引入人类偏好信号，使模型输出与人类价值观对齐。

RLHF通常包含三个阶段：首先使用人类标注的偏好数据训练奖励模型（Reward Model），然后使用强化学习算法（如PPO）优化策略模型，使生成的输出获得更高的奖励\cite{ouyang2022training}。Bai等人\cite{bai2022training}进一步将RLHF扩展到有害性（Harmlessness）对齐，训练出既有帮助性又无害的助手。

Anthropic团队提出的宪法人工智能（Constitutional AI, CAI）方法\cite{anthropic2022constitutional}探索了利用AI反馈替代部分人类反馈的可能性，通过预定义的宪法原则指导模型自我批评和修正，降低了RLHF对大规模人类标注的依赖。

然而，RLHF面临多重挑战。一方面，训练过程复杂且不稳定，需要大量高质量的偏好数据；另一方面，强化学习优化可能导致训练不稳定和灾难性遗忘。此外，RLHF可能引入"对齐税"（Alignment Tax），即对齐过程可能降低模型在通用任务上的性能。

\subsection{直接偏好优化与替代对齐方法}

为克服RLHF的局限性，研究者提出了多种替代方案。Rafailov等人\cite{rafailov2023direct}提出的直接偏好优化（Direct Preference Optimization, DPO）通过将奖励模型隐式地表示为策略函数的函数，避免了显式训练奖励模型和强化学习过程，显著简化了训练流程。

DPO的核心思想是直接在策略空间优化偏好数据，通过分析偏好对中的正负样本，推导出策略优化的目标函数。这种方法在保持与RLHF相当性能的同时，具有更好的稳定性和计算效率。Ethayarajh等人\cite{ethayarajh2024kto}提出的Kahneman-Tversky优化（KTO）进一步简化了偏好数据的需求，仅需单个样本的二元反馈即可进行有效优化。

除了DPO和KTO，还有其他偏好优化方法，如身份偏好优化（Identity Preference Optimization, IPO）和相对优势优化（Relative Advantage Optimization, RAO）等。这些方法各有优劣，在不同场景下表现出不同的特性。

\subsection{多模态模型微调与对齐挑战}

随着视觉语言模型（Vision-Language Models, VLM）的发展，多模态模型的微调与对齐成为研究热点。Liu等人\cite{liu2023visual}提出的视觉指令微调（Visual Instruction Tuning）方法，通过构建图像-文本指令对，使预训练的语言模型能够理解和生成视觉内容。

多模态微调面临独特的挑战。首先，需要实现视觉编码器和语言模型之间的有效对齐，使视觉特征能够被语言模型理解和利用。Li等人\cite{li2023blip}提出的BLIP-2方法通过冻结视觉编码器和语言模型，仅训练轻量级的查询变换器（Querying Transformer），实现了高效的视觉-语言对齐。

其次，多模态指令数据的构建比纯文本指令数据更为复杂，需要同时考虑图像和文本的语义关联。此外，多模态模型还面临跨模态越狱攻击等新的安全威胁，需要特殊的对齐策略。

\subsection{安全对齐的特殊性与对齐税问题}

安全对齐是大模型对齐的特殊且重要方面。与有用性对齐不同，安全对齐的目标是阻止模型生成有害内容，这与模型内生的指令遵循能力存在本质冲突。这种冲突导致安全对齐面临"过度拒绝"（Overrefusal）问题，即模型拒绝回答合法的良性请求。

Zong等人\cite{zong2024safety}的研究表明，在几乎不增加成本的情况下进行安全微调可以显著提升模型的安全性，但同时也可能导致模型有用性的下降，即所谓的"对齐税"。Jain等人\cite{jain2024what}通过机制性研究发现，安全微调的机制和效果与数据质量、模型架构等因素密切相关。

多模态模型的安全对齐更为复杂。Andriushchenko等人\cite{andriushchenko2025jailbreaking}证明了即使是经过安全对齐的领先大语言模型，也可能通过简单的自适应攻击被越狱。在多模态场景下，攻击者可以利用图像等视觉模态绕过文本层面的安全防护。

为了应对这些挑战，研究者提出了多种方法，包括推理时安全控制、安全模块化训练、安全推理链等。这些方法各有侧重，旨在在保持模型有用性的同时提升安全性。

\subsection{本节小结}

本节系统介绍了大模型微调与对齐的基础知识。预训练为模型提供了强大的语言理解和生成能力，指令微调进一步提升了模型遵循指令的能力，RLHF和DPO等方法通过引入人类偏好信号实现价值观对齐。多模态模型的微调与对齐面临跨模态对齐和特殊安全挑战。安全对齐作为对齐的重要方面，需要平衡安全性与有用性，避免过度拒绝和对齐税问题。这些技术和挑战为后续章节的研究提供了基础。

\section{通用大模型面临的核心风险}

近年来，\ac{LLM}的飞速发展显著提升了自然语言处理的基准，并进一步催生了视觉语言模型\ac{VLM}的多模态理解能力。然而，随着模型参数量和应用场景的扩张，其潜藏的安全风险也愈发凸显。

正常场景中，面临的多模态安全风险主要可以分为以下几类：文本风险、图片风险、图文联合风险。

安全的难点在于：安全任务和其他任务是背道而驰的。安全的目标是不输出风险内容，而模型内生的指令遵循能力又要求模型尽可能按照指令进行输出，因此强化安全能力势必削弱通用能力。
以及边界的不确定性。各类主体针对安全边界的认知存在明显差异，因此很多第三方的安全边界相对缺乏参考价值。

现有的安全性研究主要集中在以下几个核心挑战：

\begin{itemize}
    \item \textbf{过度拒绝与拒绝不足：} 模型在安全性和有用性之间存在帕累托前沿（Pareto frontier）的博弈。这导致模型要么容易被欺骗输出有害内容，要么过度保守，拒绝回答合法的良性请求（Overrefusal）。
    
    \item \textbf{越狱攻击：} 恶意用户可以通过精心设计的提示词（Adversarial Prompts）诱导模型绕过内部安全准则，生成不当或有害内容，如非法行为指令、自残建议等。
    
    \item \textbf{幻觉问题：} 模型生成事实性错误或逻辑不连贯内容的现象，在视觉语言模型中尤为严重。
    
    \item \textbf{种族歧视与偏见：} 模型在海量互联网数据预训练过程中，不可避免地吸收了人类社会存在的社会偏见。这种偏见不仅体现在文本回复中，更在图像识别与关联中被放大。例如，模型可能在视觉识别中对特定族裔产生刻板印象，或在招聘、风险评估等下游任务中表现出系统性的种族或性别歧视。这不仅是技术挑战，更是违反 AI 伦理准则的核心问题，直接影响了模型的大规模部署与社会合规性。
\end{itemize}

我们的研究主要聚焦于提高输出安全，应对拒绝不足和越狱攻击，以及通过更合理地利用外挂知识库，解决可能出现的幻觉问题。



\section{推理与部署阶段的安全增强方法}

推理与部署阶段的增强主要聚焦于在不修改模型参数的前提下，如何提升模型的输出安全能力。

\subsection{输入输出安全审核与后处理}

通过构建完整的安全审查链路以阻断不良信息的正常流转，是当前输入输出安全防护领域的主流思路，也是工业界应用最为广泛的技术方案之一。其核心设计理念在于引入一个参数量更小的轻量模型，专门负责对输入内容与输出结果进行安全校验。

该校验过程可灵活作用于两个环节：既可以对用户发起的查询请求进行前置筛查，也可在主模型完成推理生成后，对输出内容进行后置校验。典型代表模型包括 Llama-Guard、Llava-Guard、Shield-Gemma、Qwen3-Guard、WildGuard 等。

具体而言，在主模型完成推理任务后，由该轻量化校验模型评判输出结果是否违反预设安全准则，若检测到违规内容，则触发对应的后处理流程。相关后处理方案可参考 VLMGuard-R1、MLLM-Protector 等研究。

此类方法实现逻辑简洁，与主模型训练及推理流程完全解耦，具备较强工程实用性。但其局限性在于：安全能力依赖完整审查链路部署，若直接调用开源模型，仍可能生成违规内容。此外，前置分类模型泛化能力有限，当安全规则频繁调整时，需反复训练，维护成本较高。

\subsection{推理时控制与自反思机制}

推理时控制与自反思聚焦于推理过程中的实时安全管控。核心思路是在模型预测下一词元时嵌入特定采样策略，引导模型生成安全合规内容。

该类方法无需对主模型进行微调，仅在词元输出阶段介入调控，适配实时场景需求，并可动态识别和修正潜在风险。例如，Qwen3-Guard 提出流式版本以适配实时场景；ETA 通过对句子的 Best-of-N 前缀进行推理，实现过程级安全控制。

\subsection{检索增强与部署级安全}

大语言模型作为概率模型，其世界知识主要来源于预训练和中期训练阶段。由于训练成本高且周期长，当知识因时效性过时，可能引发安全风险。

为此，引入检索增强生成（RAG）机制，以解决时效性问题导致的模型幻觉。传统方法是引入外挂知识库，在回答前检索相关文档以辅助生成，减少幻觉。

伴随智能体能力发展，工业界将知识检索作为工具调用方式，由模型自主选择是否调用。例如 Search-R1 通过在思考过程中调用检索能力并进行多轮检索，解决多跳复杂推理问题，同时隐含具备处理知识密集型安全问题的潜力。

我们希望通过引入该机制强化模型的安全反思能力。

\section{基于模型训练的安全增强方法}

相较于推理阶段的介入，基于模型训练的方法旨在从根本上重塑模型参数分布与潜在表征，使其内化安全规范。训练范式已从单纯记忆不安全样本，演进为培养模型的安全推理能力（Safety Reasoning）与价值观对齐（Value Alignment）。

\subsection{构建适配器与轻量化安全模块}

该类方法在冻结主干参数的前提下，通过参数高效微调（PEFT）注入安全知识，降低训练成本并减少灾难性遗忘。

例如 Safety Fine-Tuning at (Almost) No Cost 使用 LoRA 技术进行安全微调。但后续研究指出，仅文本层面微调难以抵御视觉越狱攻击。

因此，研究开始聚焦视觉-语言对齐层。例如 SafeVLM 在视觉编码器后引入“安全投影仪（Safety Projector）”和安全 Token，用于拦截视觉风险特征。VLMGuard-R1 提出多模态提示重写器，通过后视分析与多模态因果分析将潜在风险查询转化为安全指令。

此类方法具备模块化灵活性，但在极隐晦跨模态攻击下仍受限于轻量模块表征能力。

\subsection{融入推理过程的安全有监督微调（Reasoning-Aware SFT）}

传统 SFT 依赖“问题-拒答”对进行训练，导致模型缺乏对“不安全原因”的深层理解，即“安全推理鸿沟（Safety Reasoning Gap）”。

为此，引入安全思维链（Safety CoT）。例如 GuardReasoner-VL 训练模型在输出最终标签前先生成安全推理过程，从而提升复杂攻击识别率。MIRage 数据集通过多图输入与安全 CoT 标签训练模型进行风险推理。

实验表明，该方法不仅降低攻击成功率，在部分通用任务上还提升性能。

此外，仅利用包含拒绝回复的良性指令数据进行微调，也可有效纠正模型的过度顺从偏差（Compliance Bias）。

\subsection{基于反馈的偏好对齐优化}

在 SFT 之后，偏好对齐阶段旨在实现模型输出与人类价值观的精细对齐，通常采用 RLHF 或 DPO。

传统 RLHF 面临“对齐税（Alignment Tax）”问题。Safe RLHF-V 提出多模态反馈强化学习框架，通过构建包含有用性与安全性双重偏好的数据集（BeaverTails-V），并建模为受约束优化问题，在最大化有用性的同时确保安全性阈值。

此外，PRISM 方法捕捉视觉与文本模态间细粒度交互进行偏好建模。GuardReasoner-VL 在 RL 阶段引入针对推理过程的奖励信号，确保安全判断基于逻辑推导。

未来安全训练将不再局限于简单拒答，而是向更具解释性、兼顾通用能力的精细化方向发展。
