\section{研究背景及意义}
% Qwen系列, Llama系列开源模型技术报告
% Qwen-VL系列, Intern-VL系列模型开源技术报告
近年来，\ac{LLM} 与 \ac{VLM} 在模型规模、数据规模与训练范式持续演进的推动下，在自然语言理解、多模态语义对齐、跨模态推理与生成能力方面取得了显著突破。
从早期的单模态表示学习到当前具备复杂指令跟随能力的通用大模型，模型逐步展现出接近甚至超越人类平均水平的语言组织与知识表达能力。
以 Qwen 系列、Llama 系列为代表的开源大语言模型，
以及 Qwen-VL、Intern-VL 等多模态模型的技术报告表明，
通过大规模预训练与指令对齐优化，模型能够在图文问答、跨模态检索与复杂场景理解任务中取得优异表现。

随着模型能力的提升，多模态模型已从研究实验环境逐步走向真实业务系统，成为自动化审核、智能客服问答助手、内容生成与辅助决策等核心模块的重要组成部分。
在工业级部署场景中，模型不再仅作为离线分析工具，而是嵌入高并发、低延迟、强约束的业务流程中，其输出结果往往被下游系统直接采纳，或作为人工审核与业务决策的重要参考依据，甚至直接面向终端用户提供服务。
因此，模型输出的安全性、合规性与事实可靠性，不仅影响单轮交互体验，更可能在复杂系统链路中被放大，演化为业务风险、品牌风险乃至监管风险。

以自动化内容审核场景为例，平台需要对海量图文组合内容进行实时识别与风险判断。
随着用户规避策略的演化，违规信息的表达形式呈现出明显的跨模态耦合特征，例如通过图像中隐含的敏感视觉元素配合语义模糊或暗示性文本表达，从而绕过传统关键词或单模态识别规则。
当模型未能准确建模跨模态语境中的语义关联时，可能产生“拒绝不足”（漏判违规内容）与“过度拒绝”（误判正常内容）两类问题。
前者带来合规与品牌安全风险，后者则削弱用户体验与内容生态活跃度。在高并发平台环境下，即便误判率处于较低水平，也可能因规模效应而被显著放大，形成系统性风险。

在智能客服问答助手场景中，多模态模型常用于处理包含图片的售后咨询、商品识别、设备故障诊断与政策解释等请求。
例如，用户上传设备损坏图片并询问处理方式，或提交商品图片咨询退换货规则。在此类知识密集型场景中，模型需要同时完成视觉理解、知识检索与文本生成任务。
若模型基于错误的视觉理解生成不准确建议，或在缺乏可靠依据时产生事实性幻觉，可能导致误导性答复，增加人工复核成本，甚至引发潜在安全隐患。由于客服系统通常与内部知识库、工单系统及业务流程自动化模块联动，模型输出一旦被系统自动采纳，其偏差可能在流程中级联传播，形成放大效应。

% 这里找一个多模安全评估集的图片举例
此外，在开放式对话场景中，多模态模型作为通用聊天机器人，需要面对来源复杂、意图多样的用户输入。
其中部分问题可能具有潜在恶意或现实危害性，例如询问有毒化学品的制备方法、危险装置的构造方式、规避监管的具体操作步骤，或围绕极端组织、邪教团体及涉政敏感人物进行引导性提问。
在此类场景中，模型若直接给出具备可操作性的具体方案，可能带来现实世界安全风险与合规风险。

因此，在开放域聊天场景下，安全增强的核心不再仅仅是“过滤违规输出”，而是构建一种能够识别潜在风险、理解用户真实意图，并生成“无害且尽可能有帮助”回复的能力。
这对模型的语义理解能力、风险边界表达能力以及对齐训练质量提出了更高要求。如何构建兼具可落地性与可扩展性的安全增强方案，使其在保持通用能力的同时提升在开放域的风险识别能力与事实可靠性，成为当前亟待解决的重要问题。


\section{论文主要工作内容}
% 如何体现面向真实部署 -> 通过确定安全边界
围绕上述工业部署场景下的安全挑战，本文立足于现有安全对齐方法、指令微调技术以及检索增强生成技术，提出一个面向真实部署需求的多模态安全增强系统化流程。
本文的核心目标在于明确模型的安全行为边界，并通过训练与推理阶段的协同设计，使模型在遵循指令的同时具备稳定、可控的安全决策能力。
整体思路包括两个层面：
在训练阶段，通过对齐训练将安全规则与风险边界认知嵌入模型参数空间，使其成为模型世界知识的一部分；
在推理阶段，引入隐式安全反思机制，使模型在响应用户指令时，优先完成任务理解，并在内部推理过程中判断该响应是否可能违反既有安全准则。
该安全反思过程仅存在于模型的内部思考链路中，不对最终输出显式暴露，从而在保证回复自然性的同时提升安全稳健性。

此外，本文探索训练模型具备检索工具调用能力，
使模型能够基于对用户意图的理解生成合适的检索关键词，主动召回相关知识库文档，从而在知识不确定或事实密集型问题场景中降低幻觉风险，提高输出的可靠性。

具体而言，本文工作包含三个组成部分。
第一，构建多模态安全数据合成流水线。
围绕真实部署中开放对话场景，构建覆盖不同风险类型的多模态样本数据。
在数据设计中引入结构化反思过程与规则边界说明，使模型在训练过程中学习风险识别逻辑与决策依据表达方式。
通过这种结构化数据构造方式，模型逐步将安全判断能力内化为推理过程的一部分，而非单纯依赖外部规则过滤或形式化拒答模式。

第二，构建多模态大模型安全训练框架。
基于构建的数据集，探索有监督微调（SFT）与基于验证器反馈的多模态强化学习方法，
进一步增强模型在复杂语境下的安全对齐能力。通过引入外部验证信号，对模型输出进行安全性约束与优化，
使模型在保持指令遵循能力的同时，对潜在有害内容具备更稳定的边界判断能力，从而实现价值观层面的对齐增强。

第三，在推理阶段引入 Agentic 检索增强生成机制。
在涉及政策解释、时效性信息或知识不确定性的场景中，系统允许模型自主判断是否调用外部知识库进行补充检索与验证。
该机制通过工具调用与知识回溯能力，使模型在生成前进行事实校验，从而降低知识型幻觉与错误建议风险。
相较于静态 RAG 机制，本文设计强调模型在不确定条件下的自适应决策能力，在不削弱通用生成能力的前提下提升输出的事实可靠性与安全稳健性。

\section{论文组织结构}
% NOTE: 这部分最后写完重新让GPT总结一下是怎么安排的

本文后续结构安排如下：

第二章对大模型安全风险与相关防御方法进行综述。首先梳理大语言模型与多模态模型在实际应用中面临的主要安全风险类型，包括违规内容生成、越狱攻击、事实性幻觉以及跨模态语境下的风险表达等问题；
随后总结现有安全增强与对齐方法的技术路线，重点分析推理阶段过滤机制与训练阶段对齐方法的特点与局限，为后续方法设计提供理论基础与问题动机。

第三章介绍本文提出的多模态安全数据构造方法与训练流程设计。
该部分详细说明多模态安全数据合成流水线的构建过程，包括样本类型设计、结构化反思过程构造以及规则边界表达方式。
同时，给出基于所构建数据的模型训练框架，包括有监督微调与基于验证器的强化学习训练流程，并说明整体系统化安全增强方案的实现方式。

第四章给出实验设计与结果分析。该部分首先介绍实验设置、评估指标与评测数据构建方法，然后从安全能力、越狱缓解效果以及知识型幻觉控制能力等多个维度，对所提出方法进行系统评估，并结合实验结果分析方法的有效性与适用性。

第五章对全文工作进行总结，讨论当前方案的局限性与潜在改进方向，并结合多模态模型未来的发展趋势，对安全增强方法在真实部署场景中的进一步研究方向进行展望。
