\section{问题定义与总体训练范式}

\subsection{问题定义}

本文关注多模态大模型在开放世界场景下的输出安全性建模问题。具体而言，给定包含文本查询与视觉输入的多模态交互上下文，模型需要在保持有用性与指令遵循能力的同时，避免生成违反安全规范的内容，并具备对潜在风险的识别、分析与自我纠错能力。

形式化地，设多模态输入样本表示为：
\begin{equation}
x = (x_q, x_i)
\end{equation}
其中，$x_q$ 表示用户的文本查询，$x_i$ 表示与查询相关的图像输入（可为空）。模型的目标是生成文本回复 $y$，满足以下约束：

\begin{enumerate}
    \item \textbf{安全性（Safety）：} 输出 $y$ 不得违反预定义的安全规范，例如涉及违法内容、仇恨歧视、涉政涉习、血腥暴力或其他高风险内容；
    \item \textbf{有用性（Helpfulness）：} 在满足安全约束前提下，输出应语义合理、信息充分，并尽可能满足用户真实意图。
\end{enumerate}

与传统仅在输出层面进行拒答或过滤的方法不同，本文强调模型在生成过程中具备显式的安全推理能力，即模型不仅能够判断“是否应当回答”，还应理解“为何该问题存在风险”以及“在风险约束下如何给出合理回应”。

\subsection{总体训练范式}

为实现上述目标，本文提出一种以规则约束与安全反思为核心的分阶段训练范式，通过将安全规范显式引入模型的推理与优化过程，使安全性由外部约束逐步内化为模型的生成行为。
设模型参数为$\theta$，

整体训练框架包括三个关键组成部分：

\subsubsection*{(1) 基于规则的安全反思建模}

首先建立类别到安全原则的映射关系。设问题类别标签为 $x_c$，定义映射函数：
\begin{equation}
\mathcal{P}: x_c \rightarrow p
\end{equation}
其中 $p$ 表示抽象安全原则（Principle）。

随后结合具体问题 $x_q$，将原则实例化为具体规则：
\begin{equation}
\mathcal{R}: (p, x_q) \rightarrow r^{\text{rule}}
\end{equation}
其中 $r^{\text{rule}}$ 为实例级安全规则（Rule），用于约束模型生成行为。

在生成过程中，引入隐式安全反思变量 $z$（即安全推理链）。模型生成过程可表示为：
\begin{equation}
\pi_\theta(y \mid x)
=
\sum_{z}
\pi_\theta(y \mid x, r^{\text{rule}}, z)
\pi_\theta(z \mid x, r^{\text{rule}})
\end{equation}
其中 $z$ 表示模型在生成最终回复前的安全分析与反思过程。该推理变量在训练阶段作为监督信号显式存在，在推理阶段仅作为内部思考过程，不直接输出至最终结果。

\subsubsection*{(2) 融合推理过程的有监督微调}

在监督学习阶段，构建包含规则、推理过程与最终回复的训练样本：
\begin{equation}
(x, r^{\text{rule}}, z^*, y^*)
\end{equation}
其中 $z^*$ 为目标安全推理链，$y^*$ 为目标回复。

监督损失定义为：
\begin{equation}
\mathcal{L}_{\text{SFT}}(\theta)
=
-
\mathbb{E}
\left[
\log \pi_\theta(z^*, y^* \mid x, r^{\text{rule}})
\right]
\end{equation}

亦可分解为：
\begin{equation}
\mathcal{L}_{\text{SFT}}
=
-
\mathbb{E}
\left[
\log \pi_\theta(z^* \mid x, r^{\text{rule}})
+
\log \pi_\theta(y^* \mid x, r^{\text{rule}}, z^*)
\right]
\end{equation}

该阶段使模型学习“规则理解—风险分析—安全生成”的推理结构，为后续强化学习提供稳定初始化。

\subsubsection*{(3) 基于规则验证的在线强化学习}

在初始安全能力建立后，引入在线强化学习优化模型行为。强化学习目标定义为：
\begin{equation}
\max_\theta 
\mathbb{E}_{x \sim \mathcal{D}, \, y \sim \pi_\theta}
\left[
r(x,y)
\right]
\end{equation}

若采用策略梯度形式，其梯度为：
\begin{equation}
\nabla_\theta J(\theta)
=
\mathbb{E}
\left[
r(x,y)
\nabla_\theta \log \pi_\theta(y \mid x)
\right]
\end{equation}

其中安全奖励定义为规则一致性指示函数：
\begin{equation}
r_{\text{safe}}(x,y)
=
\begin{cases}
1, & \text{若生成内容满足规则约束} \\
0, & \text{否则}
\end{cases}
\end{equation}

当生成违反安全规则时，整体奖励为零，从而对不安全行为施加强约束；在满足安全约束前提下，通过 $r_{\text{help}}$ 优化生成质量。

\subsubsection*{分阶段优化策略}

整体训练采用两阶段策略：

\begin{equation}
\theta_1
=
\arg\min_\theta
\mathcal{L}_{\text{SFT}}(\theta)
\end{equation}

\begin{equation}
\theta^*
=
\arg\max_\theta
J(\theta)
\end{equation}

其中 $\theta_1$ 为安全反思监督微调后的模型参数，$\theta^*$ 为经过规则验证强化学习优化后的最终模型。

该分阶段范式实现了安全能力从“规则理解”到“行为层面内化”的逐步过渡，在保证模型有用性的同时提升安全稳健性。

\section{安全数据来源与预处理}

\subsection{数据来源与样本构成}

在数据选择方面，本文选取文小言线上产品及网页端所承接的真实用户多模态历史交互流量作为基础数据来源。该数据覆盖真实开放环境下的用户查询分布，包含文本与图像联合输入场景，同时也包含一定比例的纯文本输入样本，能够较为真实地反映实际部署环境中的风险表达形式与复杂语境特征。

设原始数据分布记为：
\begin{equation}
\mathcal{D}_{\text{raw}} = \{(x_q^{(i)}, x_i^{(i)})\}_{i=1}^{N}
\end{equation}
其中 $x_q$ 表示文本查询，$x_i$ 表示对应图像输入（可为空）。

为构建具有代表性的安全训练数据集，本文从原始流量中筛选出以下三类问题样本：

\begin{enumerate}
    \item \textbf{明确违规类别问题：} 已被初步判定为违规类别的问题样本，涵盖涉政敏感、血腥暴力、低俗色情、儿童邪典等多种风险类型。该类样本用于强化模型在高风险场景下的规则遵循能力；
    
    \item \textbf{非违规常识问题：} 被判定为正常且属于常识性问答的问题样本，用于维持模型的基础有用性与指令遵循能力，缓解安全训练带来的过度拒答现象；
    
    \item \textbf{边界型问题：} 分类结果为正常，但语义上接近违规边界、具有潜在风险或存在歧义的问题样本，用于增强模型在灰度场景下的风险识别能力与决策稳健性。
\end{enumerate}

三类数据按照约 $1:10:2$ 的比例进行混合采样，得到训练分布：
\begin{equation}
\mathcal{D}_{\text{train}} \subset \mathcal{D}_{\text{raw}}
\end{equation}
最终构建规模约为 $4.6 \times 10^{4}$ 条的多模态训练数据集。

其中，违规样本用于提供明确的安全规则学习信号；大量正常样本用于维持模型在安全约束下的生成质量与通用能力；边界型样本则用于增强模型在风险不确定条件下的判别能力与稳定性。数据中包含文本-图像联合输入样本以及一定比例的纯文本样本，以保证模型在不同输入形态下的安全泛化能力。

\subsection{人工标注与质量控制}

为保证训练数据的准确性、一致性与可用于规则建模的可靠性，本文对筛选后的数据进行了人工复核与精细化标注。标注流程在统一的安全分类体系与操作规范下进行，确保类别定义清晰、风险边界明确。

具体标注内容包括：

\begin{itemize}
    \item 对样本是否属于违规内容进行人工确认；
    \item 对违规样本标注其具体违规类别标签 $x_c$；
    \item 对边界型问题进行风险等级与类别辅助标记；
    \item 对存在歧义或标注不一致的样本进行二次审核与一致性确认。
\end{itemize}

通过人工复核，有效降低了自动分类流程带来的误判与噪声，提高了数据标签与规则构建之间的一致性，为后续基于规则的安全反思建模与强化学习奖励设计提供了稳定的数据基础。

此外，所有数据在进入训练流程前均进行了脱敏处理，不包含可识别个人身份的信息，符合相关数据合规与隐私保护要求。

\section{基于规则的安全反思数据构建}

基于上述筛选得到的多模态问题集，本文采用 Qwen3-VL-Instruct-8B 模型进行数据合成，以构建包含显式安全约束与推理过程的结构化训练数据。

原始样本表示为三元组：
\begin{equation}
(x_q, x_c, x_i)
\end{equation}
其中 $x_q$ 为文本问题，$x_c$ 为类别标签，$x_i$ 为图像输入。

\subsection{原则与规则构建}

首先，根据类别标签 $x_c$ 构建类别到安全原则（Principle）的映射关系：
\begin{equation}
\mathcal{P}: x_c \rightarrow p
\end{equation}
其中 $p$ 表示抽象安全原则。

随后结合具体问题 $x_q$，将原则实例化为实例级安全规则（Rule）：
\begin{equation}
\mathcal{R}: (p, x_q) \rightarrow r^{\text{rule}}
\end{equation}
实例级规则用于限定模型在特定语境下的生成边界，并作为后续推理与验证的依据。

\subsection{两阶段数据合成流程}

数据合成采用两阶段生成流程。

\paragraph{第一阶段：安全推理过程生成}

在给定 $(x_q, x_i)$ 及对应规则 $r^{\text{rule}}$ 的条件下，通过预设提示模板引导模型生成显式安全推理过程（Chain-of-Thought, CoT）：
\begin{equation}
z \sim \pi_{\text{teacher}}(z \mid x_q, x_i, r^{\text{rule}})
\end{equation}
其中 $z$ 表示对风险来源、规则适用性及潜在违规点的分析过程。

为提升数据质量，对生成的推理过程进行规则一致性筛选，仅保留满足规则约束且逻辑完整的样本，从而降低噪声对后续训练的影响。

\paragraph{第二阶段：最终回复生成}

在相同输入条件下，采用不同响应模板生成最终回答：
\begin{equation}
y \sim \pi_{\text{teacher}}(y \mid x_q, x_i, r^{\text{rule}})
\end{equation}

生成的回复需同时满足以下条件：
\begin{itemize}
    \item 与第一阶段推理过程保持语义一致；
    \item 不违反实例级规则 $r^{\text{rule}}$；
    \item 在安全约束下尽可能提供合理回应。
\end{itemize}

最终，每个样本扩展为结构化三元形式：
\begin{equation}
(r^{\text{rule}}, z, y)
\end{equation}
该结构用于后续融合推理过程的监督微调训练。

\section{基于规则验证的奖励建模}

在强化学习阶段，本文设计了一个基于规则验证的多模态安全奖励验证器（Rule-grounded Reward Verifier）。该验证器不引入额外可学习参数，而是通过规则一致性判断与通用奖励模型相结合的方式，对模型生成结果进行分解式奖励评估。

整体奖励函数定义为：
\begin{equation}
r(x,y) = r_{\text{safe}}(x,y) \cdot r_{\text{help}}(x,y)
\end{equation}

其中，$r_{\text{safe}}$ 表示安全性奖励，$r_{\text{help}}$ 表示有用性奖励。

\paragraph{(1) 明确违规类别样本}

对于被标注为明确违规类别的问题样本，优化重点在于强化规则遵循行为。安全奖励通过规则一致性判定得到：

\begin{equation}
r_{\text{safe}}(x,y) =
\begin{cases}
1, & \text{若生成内容满足规则约束} \\
0, & \text{若生成内容违反规则}
\end{cases}
\end{equation}

对于此类样本，有用性奖励设为：
\begin{equation}
r_{\text{help}}(x,y) = 1
\end{equation}

即仅通过安全一致性信号进行优化。该设计避免模型在高风险场景中优化表达质量而削弱拒绝强度。

\paragraph{(2) 边界型与正常类别样本}

对于边界型及正常类别样本，默认其安全性奖励为：
\begin{equation}
r_{\text{safe}}(x,y) = 1
\end{equation}

此类样本的优化目标在于维持模型指令遵循能力与生成质量。引入通用奖励模型对生成结果进行评估，得到浮点数奖励：
\begin{equation}
r_{\text{help}}(x,y) \in \mathbb{R}^{+}
\end{equation}

该奖励反映生成内容的语义完整性、相关性与回答质量。

\paragraph{(3) 奖励组合机制}

最终奖励采用乘积形式融合：
\begin{equation}
r(x,y) = r_{\text{safe}}(x,y) \cdot r_{\text{help}}(x,y)
\end{equation}

该设计使安全性成为硬约束门控：当生成违反规则时，$r_{\text{safe}}=0$，整体奖励为零；在满足安全约束的前提下，通过 $r_{\text{help}}$ 进一步优化生成质量。

在 online-RL 训练过程中，模型对多模态输入进行 rollout 生成候选回复。验证器基于对应规则进行一致性与合规性校验，并结合通用奖励模型计算最终奖励值。
实现层面，基于自有强化学习训练框架，将多模态输入统一转换为对话接口格式，并采用异步 API 调用已部署的教师通用模型获取有用性奖励，以提升并行吞吐效率并保证在线强化学习阶段的训练稳定性。
奖励信号作为外部反馈参与参数更新，引导模型逐步学习符合安全规范的生成行为。

\section{Agentic RAG 场景下的安全验证探索}

除标准多模态输入场景外，本文进一步探索模型通过调用搜索工具处理事实性风险问题的能力，以分析检索增强机制对安全表现的影响。

\subsection{事实性风险数据构建}

我们构建了一个面向 Agentic RAG 场景的事实性风险问题数据集，用于分析模型在“检索增强 + 安全判断”复合决策过程中的行为稳定性。

数据集基于开源新闻标题构建。以新闻标题作为现实背景查询起点，通过调用内部检索 API 召回相关文档，并选取相关性较高的文档作为补充证据。为保证文档可靠性，仅选取信任域名单内的网页内容。

在此基础上，结合标题语境与召回内容自动生成具有潜在风险判断需求的事实性问题。此类问题通常涉及事实归因、事件评价或延伸推理，若缺乏时效性或背景知识，模型容易产生不准确或误导性输出。

\subsection{评估目标与实验定位}

与常规安全评测不同，该场景不仅要求模型识别内容风险，还需要其在信息不足或存在不确定性时主动利用检索工具获取外部证据，并基于检索结果进行谨慎生成。

因此，该实验主要关注以下能力：

\begin{itemize}
    \item 模型是否能够合理触发工具调用；
    \item 是否基于检索证据进行推理；
    \item 是否在事实不充分或存在争议时避免生成不当内容。
\end{itemize}

需要强调的是，本工作在 Agentic RAG 安全方向上的探索仍属于初步尝试。本文未引入专门的工具规划或复杂决策优化机制，而是在既有安全训练框架下观察模型在外部检索条件下的行为变化。

该实验旨在提供一个安全性与工具调用能力交叉评估的初步范式，为后续更系统的安全 Agent 研究提供经验参考。
